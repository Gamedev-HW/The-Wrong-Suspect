# The Wrong Suspect

# Description

The Wrong Suspect is a mystery-stealth game where you play as a criminal trying to outsmart Sherlock Holmes. Before he arrives at the crime scene, you have only a few minutes to manipulate evidence, create a convincing alibi, and frame the wrong suspect. Once time runs out, watch Sherlock investigate and discover whether your deception was successful.
